# Quantum Certification Program

> Structured quantum computing certification from fundamentals to advanced topics. Competency-based assessment and industry recognition.

## Certification Tiers

QDiana's certification follows the progression of this book:

| Tier | Name | Prerequisites | Covers | Assessment |
|---|---|---|---|---|
| **QC-100** | Quantum Foundations | Linear algebra, Python | Parts I-II (QM + QC) | 60 MCQ + 3 circuit challenges |
| **QC-200** | Quantum Developer | QC-100 | Parts II-IV (algorithms, hardware, QML) | 40 MCQ + 5 programming tasks |
| **QC-300** | Quantum Security | QC-200 | Part V (PQC) + Zipminator SDK | 30 MCQ + PQC implementation project |
| **QC-400** | Quantum Specialist | QC-300 | Domain track (finance, HPC, ML) | Capstone project |

## Competency Framework

Each tier assesses five competency areas:

1. **Conceptual understanding**: Can explain quantum phenomena and their implications
2. **Mathematical fluency**: Can work with bra-ket notation, density matrices, and Hamiltonians
3. **Programming proficiency**: Can build and run quantum circuits in at least two frameworks
4. **Hardware awareness**: Understands noise models, error rates, and backend selection
5. **Application design**: Can map real problems to quantum algorithms

## Assessment Methods

- **Multiple-choice questions**: Conceptual understanding and mathematical reasoning
- **Circuit challenges**: Given a specification, build a quantum circuit that produces the correct output
- **Programming tasks**: Implement an algorithm end-to-end in a quantum framework
- **Capstone projects**: Solve a real-world problem using quantum computing (QC-400 only)

All assessments run in browser-based quantum simulators with Colab integration.
